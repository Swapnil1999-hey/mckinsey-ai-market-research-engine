# Supabase + pgvector setup

1. Create a Supabase project.
2. Open SQL Editor and run `schema.sql`.
3. Copy the Postgres connection string from Supabase: Project Settings → Database → Connection string.
4. Put it in the backend `.env` as `DATABASE_URL=...`.
5. Optionally set `DATA_SOURCE=database` to force database mode. With `DATA_SOURCE=auto` the app uses PostgreSQL when configured and falls back to the bundled demo CSVs when it is not.
6. Run `python -m services.seed_database` from `backend` to import the bundled demo dataset into Supabase.

For semantic search, set `EMBEDDING_DIM=1536` and use the supplied `/api/data/semantic-search` endpoint with an embedding generated by your chosen embedding provider. The schema uses pgvector cosine similarity and never treats synthetic demo records as real web evidence.
